# 丸吉孝文 公式ウェブサイト (Takafumi Maruyoshi Official Website)

本リポジトリは、大阪府松原市で活動する「AIエンジニア × 政策スペシャリスト」丸吉孝文の公式ホームページのソースコードです。
「行政のオープンソース化（シビックテック）」というビジョンを自ら体現するため、本サイトのソースコードを公開しています。

## 開発者について (About the Author)
**丸吉 孝文 (Takafumi Maruyoshi)**

個人開発者として本アプリ・サイトを開発・運用する傍ら、大阪府松原市にて「政治のリアルを知り尽くしたAIエンジニア」として活動しています。2026年松原市議会議員選挙の立候補予定者でもあります。

* **職能:** 3名の地方議員を同時に支える政策のスペシャリスト ＆ AIエンジニア
* **実績:** 全国の市民の声を届ける匿名陳情システム「令和ボイス」開発者
* **視点:** 3児の父 ＆ ミズカラポテンシャル公式アンバサダー

テクノロジーの力で、無駄のない「本当に機能する行政DX」と「痛みを伴わない行財政改革」の実現を目指しています。
